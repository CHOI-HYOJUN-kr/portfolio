# 재현 가능한 범위

## 이 저장소에서 실행 가능

portfolio 저장소 루트에서 프로젝트 폴더로 이동합니다.

```sh
cd projects/LKS-Control-Optimization
python tools/verify_metrics.py
python -m unittest discover -s tests -v
```

Python 3.10 이상과 표준 라이브러리만 사용합니다. CSV 4행의 단위·유한값을 확인하고 평가식으로 J를 재계산합니다. 허용 오차는 절대 1e-6입니다. 잘못된 지표·누락된 행·J 불일치가 있으면 종료코드 1을 반환합니다.

그림 재생성은 `python -m pip install -r requirements-plot.txt` 후 `python tools/plot_metrics.py`로 수행합니다. 저장 지표의 시각화이며 시뮬레이션 신호를 생성하지 않습니다.

## 당시 수행 절차와 공개 실행 범위

보고서와 경험 기록에는 **5,000개 시뮬레이션 결과 → Random Forest 학습 → 20,000개 Q/R 후보 예측 → 상위 20개 Simulink 재실행 → 최종값 판단**의 절차가 기록되어 있습니다. 이는 학기 프로젝트에서 수행한 후보 탐색 과정의 설명입니다.

현재 공개 저장소에는 A/B/C와 보고서 선택값의 지표 4행, 결과 그림, 산술 검토·시각화 도구를 제공합니다. 위 명령은 저장 지표의 단위·수치·평가식 정합성을 확인합니다. 원본 시뮬레이션, Random Forest 학습, 후보 탐색 전체를 재실행하지 않습니다.

## 원본 모델 재실행에 필요한 것

전체 탐색을 다시 실행하려면 재배포 권한이 확인된 차량 모델·수업 제공 자료, MATLAB/Simulink와 필요한 toolbox의 버전, 차량 파라미터·gain 설계·데이터 수집·후보 평가 스크립트와 실행 설정이 필요합니다. 해당 원본 환경은 이번 공개 범위에 포함하지 않습니다.

이번 공개용 `tools/` 코드는 2026-09-09에 추가한 결과 확인 도구입니다. 학기 프로젝트 당시 작성한 제어 코드나 새 실차·시뮬레이션 시험으로 제시하지 않습니다.
