# 실물 결과와 영상 읽기

## 영상 읽기

시연의 핵심 네 구간을 연결했습니다. **1x MP4는 46초, GIF는 더 짧은 26초 분량을 2배속으로 재생한 13초**입니다. 컷 사이의 대기·이동은 생략됐으며, 각 MP4 구간에는 원본 시각이 표시됩니다.

[![공급부터 최종 적재까지 4장면의 2배속 미리보기](../assets/process-preview.gif)](../assets/process-demo-1x.mp4)

| 화면 표기 | 원본 구간 | 볼 부분 |
| --- | --- | --- |
| 01 FEED + TRAVEL | 00:08–00:18 | 공급부에서 나온 공작물과 이동하는 서보 |
| 02 PICK | 00:58–01:16 | 공작물 위로 접근한 그리퍼의 하강·파지·상승 |

GIF의 구간은 00:08–00:14, 01:06–01:14, 01:22–01:28, 10:18–10:24입니다. 같은 네 장면의 핵심 동작만 더 짧게 골랐습니다.

GIF는 동작 순서를 빠르게 보는 용도입니다. MP4는 원본 촬영 속도이며, 무음·크롭·해상도 조정 외에 동작을 생성하거나 역재생하지 않았습니다. 장비 주변 PC·배경을 덜어냈고 촬영 위치 등 원본 메타데이터는 제거했습니다.

### 영상과 제어 기록을 함께 읽기

STEP30은 공급과 POS_PICK을 중첩하고, 공급 완료·컨베이어 안정화·서보 이동 완료가 모이면 Pick으로 넘어갑니다. 영상은 실제 움직임을 보여주며, **세 내부 완료비트의 성립 시점은 영상으로 계측하지 않았습니다.** [제어 흐름](control-design.md)

이 짧은 편집본에 순차·지그재그 두 운전 전체나 X2 중단·Resume 과정을 모두 담은 것은 아닙니다. 두 패턴의 위치 호출 순서, 유지 상태와 작업자 확인 조건은 제어 문서에서 확인할 수 있습니다.

## 확인 결과

| 결과 | 근거 | 해석 범위 |
| --- | --- | --- |
| 순차·지그재그 각 8개 적재 | 최종 보고서 §5, 개인 수행 기록 | 교육용 MPS 실물 기능 확인 |
| 중단 후 수량·인덱스 유지 재개 | 보고서 §4–5, 개인 수행 기록 | 작업자 수동 확인·조정을 포함한 흐름 |
| 12:00 → 10:25 | 보고서의 시간 비교 | 95초 / 720초 ≈ 13.2%; 원측정·반복 조건 미확인 |

최종 시연 파일 길이는 약 625.43초입니다. 길이가 보고서의 10분 25초와 비슷해도 시작·종료 기준과 반복 측정을 증명하지는 않습니다. 초기 직렬 영상은 약 730.37초이며 마지막 적재 실패가 기록돼 있어 정상 사이클타임의 비교 영상으로 사용하지 않았습니다.

따라서 대표 결과는 8개 적재와 상태 유지 재개입니다. 시간 수치는 보고서의 관찰값으로 한정하며, 양산 생산성이나 안전 성능으로 확장하지 않습니다.
