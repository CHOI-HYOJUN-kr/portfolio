# 환경과 원본 구성

| 항목 | 원본 자료에서 확인한 환경 |
| --- | --- |
| PLC | Mitsubishi Q Series |
| 위치결정 | QD77MS4 / 2축 서보 / Position Table |
| PLC 편집 | GX Works2, `.gxw` |
| HMI | GP-Pro EX, `.prxe` |
| 서보 설정 | `.pcw` 파라미터 파일 |
| 실물 | 공압 실린더, 컨베이어, 그리퍼, MPS 교육용 장비 |

설치 프로그램의 정확한 버전과 최종 시연본의 바이너리 대응은 확정하지 못했습니다. 이 저장소는 기술 설명과 시연 결과를 제공하며, PLC에 내려받을 실행 프로젝트는 포함하지 않습니다.

동일 장비에서 재현하려면 최종 GX Works2·HMI·서보 설정을 한 묶음으로 확인하고 I/O 주소, 축 원점, Position Table과 실제 공작물 위치를 대조해야 합니다. 그 뒤 개별 구동 → 1개 적재 → 8개 순차/지그재그 → 중단 후 수동 확인·재개 순서로 검토할 수 있습니다. 이는 재현 점검 순서이며 이번 포트폴리오 정리에서 새로 수행한 실물 시험은 아닙니다.
