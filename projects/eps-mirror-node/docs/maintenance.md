# 기존 프로젝트와 2026년 공개 준비 변경

기준 커밋은 `fd63cf0c63229ba9b201730033895f178a99d3ca`입니다. 2025 EPS 경험과 2026-09-09 유지보수 작업을 구분합니다.

| 기존 상태 | 이번 정리 |
| --- | --- |
| 노드 파일만 있고 package.xml·설치 entry point 없음 | `eps_mirror` ament_python 패키지 구성 |
| 세 노드 버전이 함께 있고 README가 별도 eps_bringup을 가정 | 현재 진입점을 MirrorNode 하나로 정리; 옛 버전은 기존 EPS 저장소의 Git 이력에 보존 |
| 입력하면 두 controller로 바로 발행 | 실물 출력 기본 비활성화, display→실물은 별도 opt-in |
| 빈 이름·빈 points만 확인 | 관절 집합·배열·유한값·시간 순서 검사, 별도 복사 |
| 연결 스크립트가 방화벽을 끄고 기존 주소를 비움 | 사용자 주소를 받는 읽기 전용 연결 점검으로 변경 |
| Nav2/AMCL/static TF를 자동 실행, LiDAR는 비활성 | 미검증 전체 bringup을 제거하고 라우터 실행만 제공 |
| 긴 보고서·TF PDF·중복 번역 문서 | 요약·인터페이스·실행·결과·출처로 재구성 |

새 입력 검사·기본값·패키지·테스트는 Codex와 진행한 유지보수이며 당시 개인 개발 성과로 소급하지 않습니다. 원본 커스텀 코드의 MIT 선언과 작성자 귀속은 보존합니다.

변환 로직과 wrapper 분기는 Python 테스트로 확인합니다. ROS2/Colcon 실행, Gazebo·Kortex 연결, 실물 제어는 이번 환경에서 재시험하지 않았습니다. 공개용 문서의 실행 가능성은 이 범위를 구분해 평가해야 합니다.

이 폴더에는 선별 자료와 2026년 유지보수 패키지를 제공합니다. 당시 코드와 공개 이력은 [기존 EPS 저장소](https://github.com/CHOI-HYOJUN-kr/eps-mirror-node)에 보존합니다.
